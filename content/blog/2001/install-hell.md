Title: Install Hell
Date: 2001-11-28 15:49
Slug: install-hell
Category: personal
Status: published

I recently had a free afternoon and decided to test the ease of installation of my favorite Linux distro -vs- Windows 2000 Professional. My main interest was in seeing how much KRUD had improved relative to the generally easy Windows install process. The test machine was a home built AMD-k6-2 500 based system (Biostar Mobo, single PNY 256M SDRAM, single Maxtor 20G HD, Stealth 540 32M AGP graphics, Sound Blaster 128 PCI, Intel 10/100 NIC, Creative Labs 52X CD drive).<BR><BR>Windows 2000 Pro<BR><BR>Boot: 1.40PM<BR><BR>Format drives<BR>install OS<BR>reboot halfway through (installer decided it couldn't find CD drive after the stock <BR>network setup ran)<BR>restart install from beginning<BR>same result<BR>decided to customize network settings<BR>same results<BR>put in different CD drive (generix 20x)<BR>start clean install at 4.05PM<BR>install completes<BR>customize network settings<BR>run internet connection wizard<BR>run windows update to SP2 (later realize this was a horrible idea, more on that...)<BR>install FTP server from W2K CD<BR>IE crashes<BR>System freezes on shutdown<BR>Reboot to working system<BR>Finish: 5.35PM<BR>Total time: 1.5 hours (I'm only counting the one successful attempt).<BR><BR>KRUD<BR><BR>Boot: 7.05PM<BR>Select configuration options<BR>finish install <BR>use Red Carpet to grab latest updates to needed packages<BR>Finish: 7.50PM<BR>Total time: 45 minutes<BR><BR>I was rather surprised by the results, as I'd only been hoping to see that KRUD was closer to being comparable in ease of installation. It's entirely possible that the problems installing Win were BIOS or hardware issues, but I don't think that's terribly likely as the machine had previously had Windows on it with the same configuration (I simply wiped the existing install), and Linux had no troubles at all. This would tend to indicate to me either a deficiency in the Windows installer, or that Linux is better at coping with hardware problems.<BR><BR>A linux installation is highly customizable, as you can select what you want installed at a fairly granular level. In addition, there is much more installed with Linux (note that this is not a case like Windows, where the bundled apps are anti-competitive. With linux they generally include several competing applications (Abiword and KWord, for example) and let you choose which one you like, and the apps are rarely developed by the company who created the distribution).<BR><BR>After installing windows I had: GUI, Web Browser (with many security problems), email client (with many security problems), telnet client, cd player, media player, audio recorder, calculator, basic image editor (BMP format only, limited tools), some system management tools (fairly comprehensive), a few games.<BR><BR>After installing KRUD I had: GUI (several to choose from, all installed), several web browsers (Mozilla, Netscape, Galeon, Konqueror), several email clients to choose from (pine, mutt, KMail, Evolution, etc), SSH/telnet from terminal, ftp client, cd player, media player, audio recorder, calculator, advanced image editor (on par with Paint Shop Pro), system management tools, web server, ftp server, enterprise quality firewall, BIND/DNS server, mail server, several programming languages with all necessary utilities (C, Python, Perl, C++, FORTRAN, Tcl; debuggers, compilers, libraries, IDE), dozens of games (primarily strategy/card games), two enterprise level databases (MySQL, Postgre), several word processors (AbiWord, KWord), backup application, code version management system, fax application, network protocol analyzers, security tools, finance manager, data encryption tools, cd burning software, cd ripping software, ad-blocking software, complete documentation for system and applications, instant message clients (for Yahoo, AOL, ICQ, and Jabber networks), professional layout/publishing tools, remote access tools. And much more.<BR>
