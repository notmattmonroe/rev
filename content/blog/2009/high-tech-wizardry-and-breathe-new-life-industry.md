I have found myself with a Fujitsu Lifebook P7230.  I suppose it's a fine subnotebook.  It's very very light, very very small, and doesn't run <a href="http://www.apple.com/macosx/">Mac OS X</a>.   Or does it?<br /><br />I've casually followed the hackintosh movement since Apple first announced the switch to intel chips.  I've been eyeing the <a href="http://www.msimobile.com/windhome.aspx">MSI Wind</a> or <a href="http://eeepc.asus.com/">Asus eeePC</a> as possible replacements for the iBook, but they are fairly underpowered for some of the things I do (graphics editing, video editing).  And I don't want to go back to linux.   While I spent a lot less time keeping linux up and running than I did on Windows, there still was a lot more time on computer maintenance than I liked.  And getting it up and running was a bit of a hit-or-miss effort back when I was a full time linux user (late 90's to mid 2000's).  <br /><br />I played with Ubuntu on the lifebook for a few days.  Install was painless and all the hardware worked fine.  The interface was a bit more polished than last time I used linux, but still a far cry behind the cohesiveness and 'it just works' ness of OS X.  The main things I do on my computer at home are centered around digital media or python coding.  Linux has tools for both of those that are adequate, but they are just that: adequate.  For their many shortcomings, I still find iTunes and iPhoto to be the best tools for managing music and pictures.  With over 100G of music and 10G of pictures, the tools simply have to work.  The linux window managers haven't improved much.  Again, still better than Windows but not by much.  Video production on linux is simply not worth the effort for me.  As far as coding, most of the open source editors just plain suck.  They're either resource hogs like the mozilla based ones (the browser is a super crappy editing environment, even Microsoft figured that one out) or eclipse (java sucks memory and cpu out of all proportion to what is being done even under the best of circumstances).  These are not problems unique to linux.  The very best web IDE ever was HomeSite, whose brutal death at the hands of Adobe was a truly depressing event.  The second best is the very capable <a href="http://macromates.com/">TextMate</a>, which only runs on OS X.<br/><br />After many unhappy experiences with installs and upgrades I finally hit upon a winning setup.  I have a 14GB base partition, an 8GB restore partition, and the rest is user files.   In the highly likely event that I must reinstall due to <a href="http://en.wikipedia.org/wiki/Brick_(electronics)">bricking</a> it during an upgrade at least all my home directory is safe.  I also moved Applications and Library off to the user partition so I'd have room for  the <a href="http://developer.apple.com/TOOLS/xcode/">XCode</a> and <a href="http://www.apple.com/ilife/">iLife</a> installs (more on that later).  Softlinks are your friend.<br/><br />What I selected in the install process using a Kalyway 10.5.2 DVD <ul><li>Additional Fonts<li>kernel_vanilla_92<li>Intel GMA950<li>Realtek Sigmatel Conexant AnalogDevices HD Audio Codec (it doesn't work, but it was worth a try)<li>MarvellNetworkAdapter (it won't work,but why not)<li>IO80201 and Atheros wifi<li>all mobo chipsets (that's the default, didn't touch it)<li>Hardcoded_SMBIOS<li>PCGenUSB_Fix<li>PowerMangement_bundle</ul><br /><br />post install I ran the <a href="http://pcwizcomputer.com/index.php?option=com_content&task=view&id=149&Itemid=48">Universal OSx86 Installer</a> to install PC_EFI v9, then <a href="http://pcwizcomputer.com/osx86tools/">OSX86 Tools</a> to repair permissions, set extensions permissions, and clear extensions cache<br /><br />Rebooted and then <a href="http://forum.osx86scene.com/viewtopic.php?f=3&t=2554">fixed the UUID</a> so I could SuperDuper! and then didthe OSX86 Tools dance again and rebooted.<br /><br />The very first thing I did at that point was use SuperDuper! to do a full backup of the base partition to the restore partition and also to a USB drive.  After that I moved my home folder from the iBook and started installing all my other must have tools:<ul><li>Adobe Photoshop Elements 4 yes it's old, but I've got a license for it and see no reason to buy the upgrade.<li>XCode (which is 2 damn GB)<li>iLife 06, though just iMovie, as the '08 version sucks bad.<li>iLife 08 which, with GarageBand takes up a lot of real estate.  I'll possibly upgrade to 09 after the first patch is released as the new Garageband is much more guitarist friendly and the Faces function in iPhoto looks kick ass.<li><a href="http://www.hairersoft.com/Amadeus.html">Amadeus II</a> see note on Photoshop Elements<li><a href="http://rogueamoeba.com/audiohijackpro/">Audio HiJack Pro</a> for grabbing audio from anywhere<li><a href="http://www.equinux.com/us/products/coverscout/index.html">CoverScout</a>  because I have lots of music that isn't in any amazon/itunes/emusic database<li><a href="http://cyberduck.ch/">CyberDuck</a>  files gotta move<li><a href="http://www.djangoproject.com/">Django</a>  as my web development platform of choice<li><a href="http://homepage.mac.com/major4/">ffmpegX</a>  to make all video content play nice with multiple devices<li><a href="http://homepage.mac.com/major4/">HandBrake</a>  in the hopes that someday I'll finish getting a media center set up.<li>iWork '08 I don't see '09 as a compelling upgrade so I'll probably skip it<li>MacTheRipper  for backing up dvd media<li>MySQL Tools for MySQL.  I truly love meaningful names for software<li>NewerTech USB Wireless Utility, which came with my wireless USB dongle<li><a href="http://www.titanium.free.fr/pgs/english.html">Onyx</a>  for system maintenance<li><a href="http://www.majorthird.com/">Phobia Bundle</a>  which I keep telling myself I'm going to use<li>QuickTime Pro for video work<li>TextMate for coding work<li><a href="http://www.videolan.org/vlc/">VLC</a>  for video playback</ul>And then of course back up the base partition to both the restore and the external and backup the user partition to an external as well.At this point the system works except for built-in audio and built-in networking (wired or wireless) and I'm still on OS X 10.5.2, which is a fairly old release.  In part two I'll address those issues.
