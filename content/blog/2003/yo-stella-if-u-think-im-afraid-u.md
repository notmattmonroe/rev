OK, the spelling probably gives that away.  Latest version of PABlog, the fine fine blog tool that runs on this site, has been released.  You can get it from <a href="Projects/PABlog-1.7.tar.gz">here</a> or from the <a href="http://zope.org/Members/rev_matt_y/PA_Blog/PABlog%20Release%201.7/folder_contents">Zope site</a> once it's published (probably in the next 24 hours).   This version adds support for the <a href="http://zope.org/Members/to_be/htmlarea3">zopefied</a> HtmlArea3, which is also the in-browser editor for the very fine <a href="http://www.bloghorn.com/">bloghorn</a> service.  Note that this feature doesn't appear to work on any Mac browser for some odd reason.  <br /><br />Other features of note are the ability to edit and/or delete comments without jumping through hoops in the ZMI.  Note also that the problems with comments are all part of the core CMF server, not of PABlog.    Plone is still not supported, I have not yet drunk the <span style="color: rgb(102, 0, 51);">Kool-Aid</span>.
