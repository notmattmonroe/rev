<h2>Installationguide and ephemera for the blog tool.</h2><br>Tested on: <br>Zope 2.6.2/CMF 1.4.2<br>Zope 2.6.1/CMF 1.4.2<br>Zope 2.6.1/CMF 1.3.1 <br><br>Features of PABlog (running on CMF or plone)<br><br><ul><li>You can have as many weblogs on a site as you want</li><li>Customizable subjects for entries</li><li>Comment system*</li><li>Multiple editors on all weblogs</li><li>Search*</li><li>Member registration*</li><li>Member profiles (if they want)*</li><li>Publish date (decide when you want something to publish)*</li><li>Expiration date*</li><li>Calendar*</li><li>RSS Headline Syndication</li><li>Security and Access Control*</li></ul>&nbsp;*uses the underlying CMF or Plone<br><br><br><h3>Known problems</h3><br>When using CMF 1.3.1, the blogindex_html_utils needs to be edited toremove the '.css' on the stylesheet.&nbsp; Also in CMF 1.3.1, wheneditingcomments you must hit the "Change and View" button rather than the"Change button".<br><br>New in 1.8:<br><ul><li>rss generator (edit blog.rss to contain your url and blogtitle)</li><li>list last 10 comments </li><li>cleaned up css</li><li>&nbsp;there is a fork of PABlogPlone for plone users</li><li>&nbsp;changed ID generation format for cleanliness</li><li>added 'publish date' to entry edit form (note that if youare logged in &nbsp;and are the owner of the blog,you will see the entry in the main list anyway)</li><li>automatically add PABlog to Calendar Types</li><li>removed calendarBox.pt, CalendarStyle.dtml,viewThreadsAtBottom.pt</li></ul><br><br><h3>Preconditions</h3><br><ol><li>You have Zope and CMF installed.&nbsp; You will need toinstallPABlogPlone if &nbsp;you have Plone installed.</li><li>You have CMFCalendar installed. This is highly recommended,as the archiving function derives from this. If you don't have it,comment outthe relevant section of main_template. To install CMFCalendar, createanexternal method in your CMF root with the module nameCMFCalendar.Install and the function name is install, run the test, andthe move on. </li><li>You have HtmlArea3 installed. &nbsp;</li></ol><br><h3>Installation</h3><br><ol><li>run the installer (create an external method where theModule Name is PABlog.Install and the Function Name is install)</li><li>In the ZMI, go to portal_skins/PABlog, and click ondiscussion_reply. You will see a readonly version of the file and adropdown and button. Make sure that "custom" is selected, and hit thebutton. Click the Proxy tab at the top and select Manager, and hit save.</li><li>copy blog.zexp to your Zope import folder (e.g./var/Zope/import).</li><li>Back in the ZMI, select your CMF Site (in our case 'site')and import blog.zexp into the site.</li></ol><br><h3>Usage</h3><br>Simple blog tool. Create/edit posts in the folder for the currentmonth. You can put images/documents/files/etc in the same folder (it'sjust aregular Portal Folder) and access them easily.
